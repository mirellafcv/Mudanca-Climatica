# Mudanca-Climatica

# Ideia do projeto -> "GreenRats"

Uma adaptação do aplicativo "GymRats", mas com desafios em torno da emissão de poluentes e o aquecimento global.

Nesse site, um grupo de amigos tem desafios específicos e tem que registrar seu comportamento durante o dia.

Caso haja uma emissão excessiva de poluentes, impactando o meio ambiente, perderá pontos e terá que cumprir alguma "prenda".

Caso a pessoa tenha tido uma emissão econômica, ela ganha pontos.

## As bibliotecas que vou usar:
- Streamlit (para interface interativa rápida)
- Pydantic (para validação dos dados do quiz)

Streamlit: Se o objetivo for criar o protótipo do app Web com visual moderno, rankings e dashboards sem precisar escrever HTML/CSS/JavaScript. Ele já possui componentes nativos para formulários multi-etapas, botões e barras de progresso.

Pydantic: Se você estiver criando uma API completa (usando FastAPI). O Pydantic garante que as respostas do quiz (ex: quilômetros rodados, consumo de energia) entrem no formato correto e no tipo de dado esperado antes do cálculo.
