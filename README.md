# Mudanca-Climatica

# Ideia do projeto -> "GreenRats"

Uma adaptação do aplicativo "GymRats", mas com desafios em torno da emissão de poluentes e o aquecimento global.

Nesse site, um grupo de amigos tem desafios específicos e tem que registrar seu comportamento durante o dia.

Caso haja uma emissão excessiva de poluentes, impactando o meio ambiente, perderá pontos e terá que cumprir alguma "prenda".

Caso a pessoa tenha tido uma emissão econômica, ela ganha pontos.
